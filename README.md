# **Clínica Pediatrica**

Este es un programa que realiza un CRUD para administrar la gestión de datos en una clínica de pediatría. Permite dar de alta pacientes, consultarlos, modificar y eliminarlos. Tiene espacio para registrar máximo 5 pacientes.
